# clampedge

Clamp lightweight edge statistics from stdin samples.

**Site:** https://theworker02.github.io/clampedge/

## Install / run

```bash
git clone https://github.com/theworker02/clampedge.git
cd clampedge
node src/cli.js
node --test
```
