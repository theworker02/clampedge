Overview

Clamp lightweight edge statistics from stdin samples. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/clampedge.git
cd clampedge
node src/cli.js --help
node --test
